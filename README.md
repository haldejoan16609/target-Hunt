Target Hunt is a fast-paced real-time multiplayer mini-game designed for 2–8 players. Each player joins the same room using a unique room code and plays from their own device.

Players must quickly identify and tap the correct target from a busy game board. As the rounds progress, the targets become harder to find and special Chaos challenges are introduced.

The game combines reaction speed, visual attention, accuracy, and a little bit of chaos. Players earn more points for answering quickly, lose points for incorrect taps, and compete on a live leaderboard throughout the game.

Game features:

🎮 2–8 players
🔑 Private room codes
⚡ Real-time multiplayer
🎯 Target-finding challenges
📈 Progressive difficulty
🌪️ Chaos rounds
🏆 Live leaderboard
📱 Play on individual phones, tablets, or computers
🚀 Designed for easy GitHub + Railway deployment.
